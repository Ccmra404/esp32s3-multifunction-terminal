# ESP32-S3 桌面语音交互终端 v1.0.0

首个稳定发布版本，完成从硬件设计、固件适配到语音交互和资源升级的完整验证。

## 核心内容

- ESP32-S3-WROOM-1-N16R8 主控，16 MB Flash 和 8 MB PSRAM。
- 1.54 寸 ST7789 显示屏和 ES8311 + NS4150B 音频链路。
- 双 Type-C、USB 保护、数字与音频独立 3.3V 供电。
- 离线唤醒、语音对话、屏幕表情、语音播报和 MCP 设备控制。
- 支持主题资源包在线升级和中断恢复。
- 提供原理图、PCB 布局、Gerber、BOM、贴片坐标和调试记录。

## 实测结果

- 固件镜像：2,755,824 字节。
- ST7789 SPI：40 MHz，稳定运行。
- USB 差分线：两对均 64.6 mm，长度差为 0。
- ES8311 I2C：100 kHz 稳定通信。
- 主题资源包：6,237,490 字节，约 111 秒完成升级。

## 已知问题

- ES8311 冷启动偶发 I2C 写入失败，改善接线后可稳定运行，但尚未完全消除。
- 电池供电、低功耗和续航数据尚未验证，已列入后续版本计划。

## 兼容性

- 主控：ESP32-S3-WROOM-1-N16R8。
- Flash：16 MB。
- PSRAM：8 MB。
- 资源分区：8 MB。
- 固件开发环境：ESP-IDF v6.1。
